# Submission instructions

This repository is a Bob AI Hackathon entry structured per the submission template guide.

- `submission.yaml` — team + entry metadata (evaluators read this first)
- `README.md` — project front page
- `docs/` — problem statement, solution overview, architecture, setup guide
- `demo/` — video link, live URL, screenshots
- `presentation/` — slide deck
- `src/` — all source code: `src/backend/` (Hotspots API + modelling), `src/frontend/`
  (Hotspots UI), `src/portal/` (platform shell + FIR API), `src/data/csv/` (seed dataset).
  See `src/README.md`.

Keep pushing until the deadline; evaluators use the state of the repo at the deadline.
Never commit `.env` files or credentials — `.gitignore` already excludes them.
